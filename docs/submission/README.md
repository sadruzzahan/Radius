# Radius Submission Documentation Pack

Project title: **Radius: AI Assisted Hyperlocal Marketplace**

This folder contains ready-to-edit academic submission documents for the project.

## Files

- `01-project-proposal.md` - Formal proposal for class approval.
- `02-final-project-report.md` - Full report with abstract, literature review, methodology, implementation, testing, limitations, and conclusion.
- `03-presentation-slides.md` - Slide-by-slide presentation content.
- `04-presentation-speaker-script.md` - Easy presentation script to speak from.
- `05-research-review-and-dataset-plan.md` - Research paper notes, dataset plan, ML evaluation plan.
- `06-feature-explanation-guide.md` - Detailed simple explanation of how every major feature works.
- `07-demo-and-viva-guide.md` - Demo flow, login accounts, possible viva questions and answers.
- `08-setup-and-deployment-guide.md` - How to run, verify, seed, and explain deployment.
- `09-public-comment-template.md` - Team name and ID comment template for the class post.
- `10-cover-page-and-abstract.md` - Copy-ready cover page and abstract.
- `11-requirement-checklist.md` - Direct mapping from assignment requirements to project features.

Replace these placeholders in the documents:

- `[Team Name]`
- `[Member 1 Name, ID]`
- `[Member 2 Name, ID]`
- `[Course Code]`
- `[Instructor Name]`
- `[Submission Date]`
