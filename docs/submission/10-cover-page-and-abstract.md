# Abstract

Radius is an AI assisted hyperlocal marketplace where users can buy and sell secondhand products near their location. The system supports guest, registered user, and admin roles. Guests can browse public listings, registered users can create listings, upload photos, chat, report suspicious items, manage their products, and review users after completed trades, while admins can review fraud queues, resolve reports, manage users, and inspect machine learning prediction logs.

The intelligent feature of Radius is an explainable trust and fraud detection engine. When a listing is submitted, the system analyzes product image similarity, price anomaly, seller history, listing text, brand consistency, reused descriptions, and off-platform contact signals. It returns a risk score, decision, signal list, explanation list, component scores, model version, and feature snapshot hash. The project also includes price suggestion using a Random Forest regression model and candidate fraud training using TF-IDF with Naive Bayes.

Radius was developed using React, Node.js, Express, Supabase Postgres, Socket.io, and Python FastAPI. The project demonstrates how a normal marketplace can be improved with role-based access, real-time communication, admin moderation, location-based search, and AI/ML trust screening. It is suitable for academic submission and professional portfolio demonstration.

Keywords: hyperlocal marketplace, fraud detection, machine learning, role-based access, React, Express, FastAPI, Supabase, Trust Radar.
